// PRIORITY ISSUES
P1

Emoji Replaces All Imagery

Every visual section — about hero, service icons, project thumbnails, why-us image — uses emoji on gradient backgrounds instead of real photos. For a construction company, project photography is a primary trust signal. Emoji placeholder reads as "AI generated and never finished."

FIX: Replace all emoji placeholders with real project photos, workshop shots, and team imagery. Replace service emoji with SVG icons or a simple monoline icon set.
P2

Feature Tile Services Grid

Six cards in an equal grid — icon, heading, one sentence, "Learn more" link. Every service gets identical visual weight, so a visitor scanning can't tell which service is most relevant to their project. The layout signals "we filled a template" rather than "here is what we do best."

FIX: Introduce hierarchy — hero-format the primary service, stack supporting services differently. Or break the grid into two rows of varying prominence.
P2

Non-Functional Contact Form

The contact form uses `onsubmit="event.preventDefault(); alert(...)"` — a dev artifact with no actual submission. For a piping contractor, the contact form is the primary lead channel. A form that doesn't send data makes the site a brochure with no conversion path.

FIX: Wire the form to an actual backend endpoint or a form service (Formspree, EmailJS, or server endpoint). Add loading, success, and error states.
P3

Default Type & Placeholder Contact Details

Inter communicates nothing about an Indonesian industrial company. The phone number `+62 812-3456-7890` and tel link `+628****7890` are clearly fake — obvious placeholder digits.

FIX: Choose a typeface with industrial character. Replace fake phone numbers with real contact info.
