// PRIORITY ISSUES
P0

No Real Imagery for a Construction Company

Every visual section — about image, project thumbnails — uses a placeholder SVG on a gradient background. For a company whose product is physical (welded pipes, workshops, project sites), the absence of photography is a fundamental trust gap. The "PHOTO: WORKSHOP & FACILITY" label confirms the page knows these should be real photos.

FIX: Replace SVGs with real project photography, workshop facilities, and team shots. Project cards need actual images, not gradient backgrounds with icons.
P1

Form Has No Backend Submission

The contact form simulates a 1500ms delay and shows success, but submits nowhere. For a contractor's primary lead channel, this is a demo artifact. The site cannot serve as a real business site until the form actually sends data.

FIX: Wire to Formspree, EmailJS, or a real server endpoint. Add network error handling so the user sees a failure state.
P2

Uniform Type Treatment

Barlow is used identically across every heading, body, and label — no voice differentiation beyond weight changes. The type system lacks a distinctive voice for display moments. A display cut or a second face for headlines would give the typography a spine.

FIX: Add a display-oriented typeface for hero and section headings, or use Barlow's italic and expanded variants for editorial contrast.
P2

Equal-Weight Project Cards

Three project cards are identical in form — same thumbnail, same info, same hover. No signal for which project is the flagship, which is representative, which shows scope. A portfolio for a contractor needs hierarchy.

FIX: Feature one project as a hero card (larger, full-width), use smaller cards for supporting projects. Add a metrics callout (budget, timeline, tonnage) to differentiate them.
P3

No Reduced Motion or Dark Mode

prefers-reduced-motion is not handled. Fade-in animations fire regardless of user preference. Dark mode is not implemented despite dark hero and capabilities sections setting a precedent.

FIX: Add @media (prefers-reduced-motion) to disable animations. Add CSS custom properties or a toggle for dark mode.
